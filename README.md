# SnapTab

  <img src="assets/banner.png" alt="SnapTab Banner" width="100%">
</p>

> An offline, privacy-first browser extension that lets you resume reading your tabs on your phone by scanning a QR code


---

## Features

- **Instant QR code generation:** Automatically converts your tab's url to a QR code for instant scanning
- **Smart tracker stripping:** Removes tracking and marketing parameters to keep links short and private
- **100% Offline and Private:** Runs entirely in your browser with chrome local storage. Zero telemetry, tracking, or external requests.
